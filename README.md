# Tutorial for how to use this mod
Step 1.) Download BepInEx.zip and dressmaker.apworld from this github

Step 2.) Install Yuuma's Dressmaker Modloader from Nexus mods.

Step 3.) go to your dressmaker game's folder (right click the name on steam, manage browse local files)

Step 5.) Place the contents of the BepInEx folder (from the github) in there

Step 6.) Open archipelago launcher

Step 7.) "Install APWorld" > dressmaker.apworld

Step 8.) "Options Creator" > dressmaker

Step 9.) Put your player name in the box at the top, hit export. This will give you default settings YAML



## If you are the host of the archipelago, or you are the only player in your archipelago, these are your next steps:

Step 1.) put all players' .YAML files in your archipelago in the Archipelago/Players folder. Can also be JUST your file, if you just want a randomized dressmaker run

Step 2.) "Generate"

Step 3.) Open archipelago host website, upload the .zip in your Archipelago/output folder

Step 4.) create a room





## If you are NOT the host:

Step 1.) give your host the YAML, let them deal with that stuff



## EVERYBODY steps next, after the server has been launched

Step 1.) launch dressmaker

Step 2.) Open Mod Manager in the settings menu and enable Dressmaker Archipelago, restart the game

Step 3.) Go to dressmaker folder again, BepInEx > Config > DressmakerArchipelago.cfg

Step 4.) Put your archipelago's information in that config file.

Step 5.) Return to dressmaker, launch a brand new save file

Step 6.) If everything is done correctly, is should give you a bunch of notifications saying what you've unlocked as your starter items

Step 7.) Start the first commission, i recommend skipping the tutorial.

Step 8.) when you go to open the sketchbook, nothing will appear. Head back to the main menu, start the save file again and it will load



Messages in the Dressmaker thread in the archipelago server will be monitored by me (cocoyasi) for any bugs or questions
