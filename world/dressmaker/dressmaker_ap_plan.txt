PHASE 3b: CONNECTION HANDLING (started 2026-11-06)
----------------------------------------------------
Goal: losing the connection (wifi drop, server down) never
freezes or crashes the game and never loses a check. Design
(decided 2026-11-06, same as Archipelago's CommonClient):
- The server keeps all items; a new session resends them all.
- The mod keeps every check it reaches in the slot's JSON file
  (names, not IDs, so it works before login) and resends the
  whole list as ONE CompleteLocationChecksAsync call after each
  login. The server ignores repeats.
- File named by slot (always known, even offline); the seed is
  stored INSIDE the file on first login.
- Seed mismatch = treated as a mistake (wrong server): show a
  notification, stop, don't save, don't apply items. Deleting a
  save deletes its JSON file (DeleteSlot postfix), so a mismatch
  should only ever mean "wrong server".
